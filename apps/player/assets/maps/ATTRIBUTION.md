# Map data attribution

The files in `assets/maps/bd/` are generated by `scripts/build_bd_map.py`.

* **Boundaries** (divisions, districts, upazilas / thanas): Bangladesh Bureau of
  Statistics (BBS) and OCHA ROAP, administrative boundaries of Bangladesh as of
  2015, released through [geoBoundaries](https://www.geoboundaries.org/) (gbOpen)
  under the **Creative Commons Attribution 3.0 IGO** licence
  (<https://creativecommons.org/licenses/by/3.0/igo/>). The geometry was
  simplified (Douglas-Peucker) and very small islands were dropped so that it
  can be drawn quickly on a phone. These are not survey-accurate boundaries.
* **Bengali names and centre points**: [nuhil/bangladesh-geocode](https://github.com/nuhil/bangladesh-geocode),
  MIT licence, Copyright (c) 2014 Nuhil Mehdy. Bengali names of the metropolitan
  thanas and a few upazilas were added by hand.
* District names use the common modern English spellings (for example Cumilla,
  Chattogram, Jashore).

The game shows this attribution in the Map Puzzle settings.
